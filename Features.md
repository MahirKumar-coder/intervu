# Features

## Authentication
- Login
- Signup
- JWT
- Google Login (Optional)

## Dashboard
- Previous Interview
- Interview History
- Scores
- Profile

## AI Interview Generator

### User Choices
- Job Role
- Experience
- Skills
- Difficulty
- Number of Questions

**Example:**
- Role: Frontend Developer
- Experience: 2 years
- Skills:
  - React
  - Node
  - MongoDB
- Difficulty: Medium
- Questions: 10

## Interview Room
Each question includes:
- Question
- Timer
- Answer Box
- Next Button
- Previous Button

### Later Additions
- Voice Input
- Webcam

## AI Evaluation
After submission, the AI evaluates:
- Communication
- Technical
- Confidence
- Suggestions

**Example Evaluation:**
- Communication: 8/10
- Technical: 9/10
- Confidence: 7/10
- Suggestion: Improve React Hooks knowledge.

## Report
Generate:
- Overall Score
- Strength
- Weakness
- PDF Report
